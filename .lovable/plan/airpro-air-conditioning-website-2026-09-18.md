# Airpro Air Conditioning website

## Goal
Build a premium, responsive local-service website that makes calling Airpro or preparing a quote enquiry effortless, while keeping every claim grounded in the supplied business information.

## Pages and navigation
- Create dedicated Home, About, Services, Reviews, Contact, Privacy Policy, and Cookie Policy pages with a shared header and footer.
- Add the compact 24-hour contact strip, prominent click-to-call links, accessible mobile menu, and persistent mobile “Call Now” action.
- Keep the home page conversion-focused with a concise overview and clear paths to the deeper pages.

## Visual direction
- Use a restrained deep-charcoal/navy, white, cool-grey, and ice-blue token palette.
- Pair strong modern sans-serif headings with highly legible body type, generous spacing, precise grids, restrained corners, and subtle shadows.
- Use neutral, clearly non-business-specific installation placeholders because no supplied photographs were available and the existing public website blocked automated access.
- Add only subtle reveal and hover motion, with reduced-motion support.

## Content and sections
- Build the supplied hero copy, 4.7/5 Google rating, phone number, address, 24-hour availability, and Birmingham service-area messaging.
- Present the substantiated reasons to choose Airpro using concise text and restrained line icons.
- Show confirmed installation and unit-location guidance first; clearly label servicing, repairs, commercial work, and maintenance plans as owner-editable/unconfirmed rather than presenting them as offered services.
- Add the four-step installation process and review-theme summaries without invented quotations, names, certifications, brands, guarantees, pricing, or statistics.
- Keep the Google reviews destination as an obvious editable link placeholder until the real link is supplied.

## Contact experience
- Build an accessible mobile-first quote form with Name, Phone Number, Email, Postcode, Service Needed, Message, and consent.
- Validate required fields, formats, consent, and length limits in the browser.
- On submission, prepare a structured enquiry in the visitor’s email app; keep the recipient address as one clearly documented editable business value because no quote email address was supplied.
- Keep “Call Now” visible beside the form as the fully working fallback.
- Embed a lightweight address-based Google map and provide a directions link without adding live Places searches or paid request patterns.

## Search and accessibility
- Give every content page unique British-English title, description, Open Graph metadata, canonical path, and logical heading structure.
- Add appropriate local-business structured data using only supplied facts, plus semantic landmarks, labels, focus states, keyboard support, descriptive alternative text, and strong contrast.
- Ensure touch-friendly controls, deliberate single-column mobile layouts, fast-loading assets, and no horizontal overflow.

## Technical approach
- Use reusable shared navigation, footer, call action, page-heading, and form pieces within the existing TanStack application.
- Define all visual values as semantic design tokens in the global stylesheet and use the existing responsive utility system.
- Keep the quote handoff browser-based with no database or stored personal information.
- Verify desktop and mobile rendering, menu behavior, telephone links, form validation/handoff, navigation, metadata, and absence of runtime errors.
